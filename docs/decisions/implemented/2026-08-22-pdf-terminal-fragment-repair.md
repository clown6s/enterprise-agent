# Problem

PDF 文字层在页末可能被解析为短残片，例如“进行合”，并直接进入 Milvus，导致模型忠实输出不完整句子。该问题发生在 PDF 抽取/入库阶段，需在重新上传前修复一类结构性跨页残片，而不是针对具体短语加规则。

# Decision

在页码信息仍存在时，对页末 1～3 个中英文字符、无终止标点且下一页有自然正文开头的高置信片段进行跨页合并。排除标题、列表、页码、乱码和标点完整短句；无法确认时保留原文。正常长文本和现有图片 OCR 闸门不变，pdfplumber/pypdf 都经过同一修复阶段。

# Consequences

重新解析后，高置信跨页残片会与下一页开头合并，避免残句进入 Milvus；合法短标题和模糊短行保持不变。该规则不保证修复所有 PDF 文本层错误，低置信情况宁可保留，后续可通过诊断日志发现。

旧文档已经含有残片，必须删除后重新上传/摄入；修改代码不会修复既有向量数据。
