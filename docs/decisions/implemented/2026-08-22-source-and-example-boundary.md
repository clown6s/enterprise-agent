# Problem

知识问答答案可能将模型自行补写的说明性示例与资料事实混合，且模型正文来源尾注会与 Web/飞书结构化来源重复。上传文件上下文路径还可能只返回“无来源”。

# Decision

系统提示和校验提示明确区分资料事实、解释和说明性/假设示例；没有资料依据的具体示例必须明确标注为非资料原文。答案守卫统一删除末尾的“（来源：...）/（出处：...）”尾注，结构化 `sources` 作为唯一来源展示入口。文件上下文若带有文件名/来源字段则纳入结构化来源。流式与非流式继续共享知识问答函数和校验链。

# Alternatives

- 只靠模型提示：不能稳定消除重复来源或未标注示例。
- 只在飞书卡片隐藏来源：Web/SSE 仍重复，协议不一致。
- 删除所有“例如”句：会误删资料中真实示例和正常解释。

# Consequences

来源展示更一致，资料之外的说明性示例需要明确标注。当前示例边界主要由提示和事实校验模型执行，未对所有中文示例做激进正则删除，避免破坏合法解释；结构化来源依赖文件上下文携带明确文件名/来源字段。
