# Problem

模型可能先给出事实答案，再追加“资料中未涉及相关内容/无法回答”等互相矛盾的否定句，造成用户看到自相矛盾的回答。既有守卫只清理固定的“暂无法回答”混入句，覆盖不足。

# Decision

新增独立语义守卫 `strip_contradictory_denial`，维护一组明确的资料不足/无法回答短语。答案存在实质内容时删除包含这些短语的完整句；纯否定输出统一返回 `NO_ANSWER`；已有标准兜底保持不变。守卫加入既有 `GUARD_REGISTRY`，不修改 `fix_output()` 格式重建引擎，也不针对“四公子”写特例。

# Alternatives

- 仅增加“四公子”关键词规则：只能修一个实例，无法覆盖同类错误。
- 修改提示词要求模型不要自相矛盾：不能保证模型输出稳定。
- 将规则塞入 `fix_output()`：会混合语义守卫与格式重建职责，破坏现有边界。

# Consequences

事实答案后的明确否定尾句会被确定性删除，纯否定答案会回到标准兜底。规则只匹配明确的 unsupported 句式，不处理普通内容中的任意“未涉及”字样；后续如需更精确的问句相关性判断，应在带 query 的校验阶段扩展，而不是继续扩大无上下文正则。
