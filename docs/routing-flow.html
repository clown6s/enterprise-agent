确定性规则与守卫 数据查询与已验证知识 LLM 生成与执行流程
1
注入拦截确定性正则
命中条件：问句含注入句式（"忽略以上所有指令…"）
→ 返回：拦截话术（INJECTION_BLOCKED）
2
采纳直答查表直答 · 零 LLM
命中条件：问法与 👍 采纳过的问答精确匹配（归一化比对）
→ 返回：已采纳答案 + 来源；👎 两次自动停用回慢路径
3
多跳编排拆解 · 分派 · 合并
命中条件：复合问句（多问号 / "还有" / "以及"）
→ LLM 拆成 ≤4 子问 → 每片走第 4/5 层 → 带标签合并返回
4
能力总线代码 handler 直答 ⚠ 员工 3 条待并入 NL2SQL（待拍板）
命中条件：5 条内置正则（员工人数 / 员工信息 / 员工电话 / OA 报销 / 经营数据）+ 后台可改触发词/优先级/停用
→ 返回：确定性答案 / 图表（OA 数据走 7000 接口）
5
NL2SQL 表查询注册表驱动 · 查数据库
命中条件：事实型问法（产品/价格/多少/电话…）且表已注册（query_schema，含 grants 权限）
→ LLM 生成 SQL → 五关合规校验 → 参数化执行 → 中文列名格式化返回；不可答继续下一层
6
docwizard文档流程
命中条件：文档生成/修改触发词 + skill 开关
→ 返回：飞书云文档链接
7
待确认单人机协同闸门
命中条件：存在请假待确认单且回复「确认/取消」
→ 返回：提交 OA 回执 / 已取消
8
SOP 请假多步状态机
命中条件：请假触发词 + skill 表与 SOP 页双开关
→ 查名册 → 提取参数 → 确定性校验 → 提交前确认 → 提交 OA
9
route() 正则路由确定性正则
命中条件：闲聊前缀（你好/谢谢…）→ CHAT；指代/怎么办且无历史 → CLARIFY
→ 返回：闲聊直答 / 追问澄清
10
知识问答（兜底）检索 · 生成 · 校验链
命中条件：以上全部未命中
→ 追问改写 → 检索（含扩展）→ 维度闸门 → 生成 → 校验链 → 相关性闸门 → 失败走图谱兜底 → 兜底句式
未命中任何层 / 资料无依据 → 「根据现有资料，暂无法回答该问题」
